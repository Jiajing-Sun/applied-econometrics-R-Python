# 第3章：基本概率与统计推断

## 数据与样本

本章使用脚本生成的掷骰及覆盖率模拟，不读取真实经济数据。

`set.seed(20260524)`／Python对应种子固定模拟；同一数字种子在R和NumPy中不保证抽到同一序列。公平六面骰取值1至6，理论均值3.5，方差35/12。50次投掷构成一份样本，Monte Carlo重复10000次；中心极限定理图另使用50000次重复；置信区间覆盖率实验重复5000次、每次样本量30。

区分一次样本中的50个观测和10000次重复实验。模拟结果随抽样实现有误差，不能要求经验覆盖率恰好等于名义覆盖率。

## 运行与输出

先按配套代码根目录说明准备R/Python依赖，再在本章目录执行：

```bash
Rscript R/chapter03.R
python3 python/chapter03.py
```
