# 2026年9月22日修订数据说明

## 第4章：经济体样本

原始 WDI 数据仍采用本地教学包中的历史快照。本轮未用当前 API 覆盖原指标数据。2024年人均 GDP（2015年不变价美元）与寿命完整的236行中，排除44行地区、世界和收入组等汇总行，保留192个经济体。

- 输入：`processed/wdi_global_selected_indicators_wide.csv`。
- 世界银行经济体元数据：`metadata/wb_country_metadata_20260922.json`，来源 https://api.worldbank.org/v2/country?format=json&per_page=400 ，本轮审校保存的2026-09-22快照。
- 地区、收入组仅用于描述当前快照分类，不作为2024年历史分类。
- FCS（受脆弱性和冲突影响的情形）是历史数据中的汇总组，但未在本次经济体元数据端点返回；生成器将它作为有名的例外剔除，不会静默删除其他未知代码。
- 剔除名单：`metadata/chapter04_excluded_aggregates.csv`。
- 验证：`python data/scripts/prepare_chapter04.py`。添加 `--write` 可重建样本。

## 第13章：补充模拟数据

`chapter13_event_common_timing_simulated.csv` 用于共同处理时点的事件研究；`chapter13_scm_cities_simulated.csv` 用于模拟城市的合成控制演示。两者均由固定种子20260922生成，不能解释为任何真实城市或政策的实证证据。生成器为 `scripts/generate_causal_simulations.py`。

原书 FARS 与 ACS 例子继续保留：本轮从项目本地备份恢复教学包里缺失的 CSV，来源路径和 SHA256 见修订工作目录的 `核验记录/从本地备份恢复的数据.json`。FARS 控制项中删除政策可能影响的 fatal_injury；其选择性样本、年龄离散及缺失数据限制在正文说明。

## 可重复性边界

这里的“冻结”是保存已有本地文件及哈希，不表示重新下载并更新所有原始数据。WDI 历史数据可能后续修订；时间序列例子使用历史快照回溯教学，不是使用当时已发布数据的实时预测实验。原有中国房价、中国 GDP 等教学例子保留。
