# 基础篇正文示例（第 2—5 章）

每个 `.R` / `.py` 文件只汇集该章相应语言的正文代码框，按书中顺序排列，无审查断言。请将工作目录设为本版的 **配套代码** 根目录，再运行，例如：

```sh
Rscript "修订补充示例/第二轮/ch02_正文代码框.R"
python "修订补充示例/第二轮/ch02_正文代码框.py"
```

使用已安装教材依赖的项目环境。每章从头单独运行，避免依赖其他章遗留的对象。Python/R 交互环境会显示裸表达式；作为脚本运行时，可在希望显示的表达式外加 `print(...)`。冻结数据位于 `data/processed`，不要用在线重下载结果覆盖。

这些脚本的同一正文代码已在二轮审查中按章执行；数值检查、执行日志及代码框定位单独保存在审查记录“基础篇代码框实跑”目录。
